# Установка Harp Orchestrator

Пошаговая установка с нуля на чистый компьютер с Windows.

## 1. Что нужно заранее

| Требование | Зачем | Где взять |
|---|---|---|
| Windows 10 или 11 | Приложение собрано под Windows | — |
| Node.js 22 или новее | На нём работает приложение и оркестратор | [nodejs.org](https://nodejs.org) |
| Git | Чтобы скачать проект | [git-scm.com](https://git-scm.com) |
| Видеокарта с Vulkan | Для локальных моделей. Без неё можно работать на процессоре, но медленно | — |
| Свободное место | ~1 ГБ на программу, плюс 3–10 ГБ на каждую локальную модель | — |

Проверь, что Node.js встал:

```powershell
node --version
```

Должно показать `v22` или выше.

## 2. Скачать проект

```powershell
git clone https://github.com/iser69/harp-orchestrator.git
```

Перейди в папку проекта:

```powershell
cd harp-orchestrator
```

## 3. Установить зависимости

Зависимости не хранятся в репозитории, их нужно поставить отдельно:

```powershell
npm.cmd install --prefix desktop
```

Затем доустанови Electron (без этого шага приложение не запустится):

```powershell
node desktop/node_modules/electron/install.js
```

## 4. Собрать приложение

```powershell
.\build-desktop.cmd
```

Скрипт соберёт интерфейс и создаст **Harp Orchestrator.exe** в корне проекта. Этот файл и запускает программу.

Если сборка ругается на `csc.exe`, значит не хватает .NET Framework — он входит в Windows, но может быть отключён в «Компонентах Windows».

## 5. Подключить Codex и Claude Code

Оркестратор запускает уже установленные CLI под твоими аккаунтами. Платные API-ключи не нужны, достаточно подписок.

Установи их:

```powershell
npm.cmd install -g @openai/codex
```

```powershell
npm.cmd install -g @anthropic-ai/claude-code
```

Войди в каждый (откроется браузер):

```powershell
codex login
```

```powershell
claude auth login
```

В Claude Code выбирай аккаунт Claude.ai с подпиской.

Проверь, что оркестратор их видит:

```powershell
node orchestrator.mjs doctor
```

Если Windows не находит нужный файл, укажи полный путь вручную через переменные `$env:ORCHESTRATOR_CODEX_EXE` и `$env:ORCHESTRATOR_CLAUDE_EXE`.

## 6. Локальная модель Inkling (планировщик)

Inkling составляет план и распределяет задачи между Codex и Claude. Один раз запусти установку:

```powershell
.\inkling.ps1 -Setup
```

Скрипт сам скачает движок llama.cpp с поддержкой Vulkan и веса модели (около 8,5 ГБ) в папку `.runtime`, затем поднимет сервер на `127.0.0.1:8001`.

В следующие разы достаточно:

```powershell
.\inkling.ps1
```

Если Vulkan не работает, есть режим для процессора:

```powershell
.\inkling.ps1 -Cpu
```

Установка Inkling не обязательна: если выбирать одного исполнителя (только Codex или только Claude), планировщик не нужен.

## 7. Своя локальная модель (необязательно)

Второй слот под локальную модель работает на порту `8002` и принимает любую модель в формате GGUF. Движок llama.cpp уже стоит после шага 6.

1. Скачай файл модели в формате GGUF и положи его в папку `.runtime/models/`.

   Проверенный вариант для видеокарты с 8 ГБ памяти — Qwen3 8B без цензуры (~4,7 ГБ):

   ```powershell
   curl.exe -L -o ".runtime/models/qwen3-8b.gguf" "https://huggingface.co/mradermacher/Huihui-Qwen3-8B-abliterated-v2-GGUF/resolve/main/Huihui-Qwen3-8B-abliterated-v2.Q4_K_M.gguf"
   ```

2. Открой файл `desktop/qwen-model.cjs` и в третьей строке впиши имя своего файла и название модели:

   ```js
   const url='http://127.0.0.1:8002', model='моя-модель',
         file=path.join(root,'.runtime/models/qwen3-8b.gguf');
   ```

3. Там же, в функции `stop`, замени строку поиска процесса на кусок имени своего файла — иначе кнопка «Остановить» не найдёт сервер.

Модель включается кнопкой в настройках приложения.

### Сколько памяти займёт модель

Ориентир для видеокарты на 8 ГБ: модель на 8 миллиардов параметров в сжатии Q4 занимает около 5,6 ГБ и оставляет запас на рабочий стол. Модель на 4 миллиарда — около 3 ГБ.

Если модель не влезает, уменьши контекст в том же файле: параметр `--ctx-size`.

## 8. Запуск

Открой **Harp Orchestrator.exe**, выбери папку проекта и напиши задачу.

В списке исполнителей можно выбрать:
- автоматическое распределение через Inkling,
- только Codex,
- только Claude Code,
- свою локальную модель.

Нажми «Составить план», проверь его и запусти задачи. Результаты, отчёты и журналы открываются кнопкой «Открыть результаты».

## 9. Если что-то пошло не так

**Приложение не открывается.** Запусти из папки проекта `npm.cmd --prefix desktop start` — в окне консоли будет видна настоящая ошибка.

**Модель не запускается.** Загляни в журнал `.runtime/qwen-server.log`. Частые причины: не хватило видеопамяти (уменьши `--ctx-size`) или файл модели лежит не по тому пути.

**Модель отвечает очень медленно.** Скорее всего, она не влезла в видеопамять и считается на процессоре. Проверь, не запущены ли одновременно две модели — Inkling на порту 8001 и своя на 8002 делят одну видеокарту.

**Модель вместо работы пишет инструкции.** Так ведут себя слабые модели. Помогает модель покрупнее: 8 миллиардов параметров вместо 4.

## Важно про безопасность

Локальная модель может читать и перезаписывать файлы **внутри выбранной папки проекта**. За её пределы она не выходит.

Команды PowerShell выполняются только после твоего подтверждения в диалоге и работают с правами твоего пользователя Windows. Рабочая папка команды не является песочницей — не подтверждай команды, которых не понимаешь.
