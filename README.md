# Harp Orchestrator

Inkling 2 Mini составляет план и назначает исполнителей. Оркестратор запускает штатные Codex CLI и Claude Code под твоими аккаунтами. Для запуска нужны Node.js 22+, Codex CLI, Claude Code и доступ к обоим инструментам в подписках. Inkling работает через локальный `llama-server` на `127.0.0.1:8001`. Платные API-ключи для этого сценария не нужны.

**Устанавливаешь впервые? Начни с пошаговой инструкции: [INSTALL.md](INSTALL.md)**

## Приложение для Windows

Открой **Harp Orchestrator.exe**, выбери папку проекта и напиши задачу. В списке исполнителей можно выбрать автоматическое распределение Inkling, только Codex или только Claude Code. Для одного исполнителя Inkling запускать не требуется. Нажми «Составить план», проверь его и нажми «Запустить задачи». Коммиты, отчёты и журналы доступны через «Открыть результаты».

Интерфейс работает на Electron + React. Для сборки из исходника запусти build-desktop.cmd. При восстановлении зависимостей выполни npm.cmd install --prefix desktop и node desktop/node_modules/electron/install.js.

## Запуск в PowerShell

1. Один раз войди в аккаунты через `codex login` и `claude auth login`. В Claude Code выбери аккаунт Claude.ai с подпиской.
2. Запусти `./inkling.ps1 -Setup` в отдельном терминале. Скрипт скачает llama.cpp с поддержкой Inkling и веса `IQ2_XXS` размером около 8,5 ГБ, затем запустит сервер. При следующих запусках достаточно `./inkling.ps1`. По умолчанию используется устройство `Vulkan0` с частичным размещением весов в RAM. При проблемах с Vulkan доступен `./inkling.ps1 -Cpu`.
3. Во втором терминале, открытом в папке оркестратора, выполни:

```powershell
node orchestrator.mjs doctor
node orchestrator.mjs plan --project 'D:\Мой проект' --goal 'Добавь поиск по списку задач и проверь пустой результат'
Get-Content -Encoding utf8 plan.json
node orchestrator.mjs run plan.json
```

Замени `D:\Мой проект` на реальный путь к своему проекту. Выполняй `run` после того, как `plan` сообщит, что файл сохранён.

`plan` принимает любую существующую папку. Для обычной папки или Git-репозитория без коммитов агенты работают прямо в ней; установка Git не требуется. Для Git-репозитория с коммитами сохраняется отдельная рабочая ветка. При наличии коммитов он записывает текущий `HEAD` в план и отправляет Inkling описание задачи и список верхнеуровневых путей. Можешь отредактировать план перед `run`. Для другого файла укажи `--out новый-план.json`.

Для проекта с коммитами `run` создаёт отдельную ветку `orchestrator/<id>` и рабочий каталог `.runs/<id>/project` из коммита, записанного в плане. Агенты работают последовательно в этом каталоге. Оркестратор коммитит изменения после шагов реализации и передаёт отчёты и хеши коммитов дальше. Последний шаг проверяет изменения и записывает замечания в Markdown. Каждый запуск печатает путь к ветке, рабочему каталогу и журналам. Незакоммиченные изменения исходного проекта остаются в исходном каталоге. Слияние выполняется вручную после просмотра результата. При ошибке оркестратор останавливается и оставляет рабочий каталог для разбора.

Если Windows не находит нужный бинарник, укажи его полный путь через `$env:ORCHESTRATOR_CODEX_EXE` или `$env:ORCHESTRATOR_CLAUDE_EXE`. Для Claude, установленного через npm, оркестратор ищет `claude.exe` рядом с пакетом автоматически.

На этом компьютере для работы из песочницы установлен отдельный штатный Codex CLI в `.runtime/codex`. Оркестратор находит его автоматически. Для восстановления этой установки используй `npm.cmd install --prefix .runtime/codex --no-save @openai/codex@0.171.0`.

## Локальная модель в Harp

В рабочей сессии и настройках показывается состояние Inkling. Кнопка «Запустить модель» запускает загрузку на ПК. Статус автоматически обновляется до «Готова к работе» или сообщения об ошибке.

«Только Inkling · локально» выполняет запрос на ПК. При выборе проекта модель может читать папки и файлы, создавать и перезаписывать файлы внутри проекта. Команды PowerShell запускаются после подтверждения с правами пользователя Windows; рабочая папка команды не является песочницей. Без проекта доступен текстовый ответ. До 12 шагов на запрос, тайм-аут команды — 60 секунд. Журнал инструментов tools.log и итог сохраняются в истории, токены всех шагов учитываются в статистике.

«Inkling распределяет задачи» создаёт план для Codex и Claude Code в выбранном проекте. После просмотра плана кнопка запуска передаёт шаги агентам.


## Браузер локальных агентов
Inkling, Qwen и пользовательские модели имеют инструменты web_open, web_read, web_click, web_fill и web_screenshot. Используется отдельный браузер Edge через Playwright, без личного профиля и сохранённых входов. Сайты исполняют JavaScript; модель получает текст и список элементов. Ввод текста и нажатия кнопок подтверждаются пользователем. Скриншоты PNG сохраняются в каталоге запуска и доступны через «Открыть файлы». Изображение не передаётся текстовой модели. После запроса браузер закрывается.
